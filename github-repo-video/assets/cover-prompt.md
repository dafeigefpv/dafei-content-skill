# 封面提示词模板（3:4 竖版 · 深色渐变风 · 无人像变体）

> 用法：把 `{标题}` / `{数据标签}` / `{主视觉道具}` / `{底座}` 替换掉，其余**逐字保留**——
> 留白比例、边距约束、遮挡关系这几句是实测调出来的，改一句就可能翻车（见第十二节）。
>
> **🚫 页脚 / 徽章 / 水印永不进提示词**（P26）：它们由 `fix_cover.py` 统一补。
> 提示词末尾加否定句「无页脚，无徽章，无水印」，标题注明「只出现一次」。
>
> 本次实例见 `github-repo-video/cover/cover-prompt.md`（VoiceStudio 版，含 v1→v3 实测数据）。

## 生成参数

| 项 | 值 |
|---|---|
| 工具 | 内置生图 `ImageGen`（**单张约 5–10 积分**，失败重跑同样计费） |
| `size` | `1152x1536`（3:4） |
| `quality` | `high` |
| 生图后 | **立刻改名 `cover/raw.png`**（坑位 16），再跑 `script/fix_cover.py` |

## 提示词

```
3:4 竖版构图，构图疏朗，上下留白明显。

画面最上方约四分之一是完全空白的渐变背景，不放任何元素，形成大片呼吸空间。

中文大字"{标题}"横排居中，放在画面中部偏上的位置，超粗中文黑体，无衬线，字体方正硬朗，类思源黑体 Heavy，纯白色，添加轻微黑色投影，横向占画面宽度约四分之三，行距紧凑，字距略微拉开，形成强烈的视觉冲击；标题上方留出大片空白背景。

标题正下方紧接一个高饱和亮黄色矩形色块，里面是黑色超粗字"{数据标签}"，像警示牌一样醒目，黄标签与标题之间只留极窄间隙。

黄标签下方留出一段明显的空白背景，不直接接任何物体。

{主视觉道具}

{底座}横放在画面偏下的正中央，宽度约占画面宽度的一半，正面有一排细小的指示灯，其中两颗亮着淡蓝色，表面是拉丝金属纹理和几颗六角螺丝，侧面贴一张白色小标签，上面写着"LOCAL"。

细密的声波弧线由亮蓝色细线构成，密度均匀、线条干净，从上方空白背景中飘下，绕过标题，沿着主体向下滑落，汇入下方{底座}顶部的缝隙里。

主体左右两侧各悬浮一个极小的扁平图标：左侧是一个云朵，云朵外圈画一道斜杠，右侧是一个向下的小箭头，两个图标都只有拇指大小，只做点缀。

{底座}底边与画面底边之间保留约六分之一的完全空地面，只有背景渐变与柔和反光，不放任何元素。

背景：深藏青到克莱因蓝的深色渐变，柔和过渡，上方偏深、下方偏亮。

所有元素集中在画面中部，距画面左右两边至少保留约 12% 边距，顶部与底部留白更多。

悬浮元素轻微投影，视觉层次感，高饱和度，又整齐又凌乱的美感。
```

## 填空建议

- `{标题}`：**≤6 个中文字**。取自文案的反差点或金句（例：「本地配音自由」）。
  中文越少，模型写错字概率越低。
- `{数据标签}`：主打数据，`29.8k★` 这种（**不写中文**）。
- `{主视觉道具}`：**高度约占画面高度的三分之一**，写清形态 + 「尺寸精致、不夸张」。
- `{底座}`：横放的实体容器（硬盘盒 / 机箱 / 服务器），
  「约一只鞋盒大小」比「约成年人躯干大小」更能压住尺寸。

## 预算红线

顶部留白 + 标题 + 标签 + 空隙 + 主视觉 + 底座 + 底部净空 **≤ 100%**。
加顶部留白就必须减主体——否则模型会从底部扣，页脚会被压（第十二节有实测数据）。
