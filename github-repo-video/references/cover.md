# 封面（3:4 竖版）

封面**不参与渲染**，是独立的一张 3:4 图 —— 但它决定有没有人点进来。

---

## 一、分工：skill 出提示词，脚本做后期

| 阶段 | 工具 | 干什么 |
|---|---|---|
| 1. 出提示词 | `gbro-cover-design` skill | 三轮提问定风格 / 标题 / 色调 → 填 `assets/cover-prompt.md` 出提示词（只换 4 个变量，留白 / 边距 / 遮挡已调好） |
| 2. 生图 | 内置生图（`ImageGen`） | `size=1152x1536`、`quality=high`；**单张约 5–10 积分，先告知用户** |
| 3. 后期 | `scripts/fix_cover.py` | 去水印 → 补项目名 / 系列徽章 → 3:4 成图 → 版式体检 |

**为什么是 3:4**：与成片同比例，封面与视频在信息流里是同一套视觉语言；
1152×1536 再放大到 1440×1920，与成片逐像素对齐。

---

## 二、固定版式（六条，改一条就要全系列重做）

1. **画幅** 3:4（1152×1536 出图 → 1440×1920 交付）
2. **背景** 深藏青 → 克莱因蓝，对齐 `board_css` 的主题色 `#002fa7` —— 与成片同色系，形成系列观感
3. **风格** 深色渐变风（`gbro-cover-design` 十种里的第一种），无人像变体
4. **标题** ≤6 字中文大字，纯白超粗黑体 + 轻微投影，横向占画幅约 3/4
5. **数据标签** 标题正下方紧接高饱和亮黄矩形 + **黑字**（不是黄字），像警示牌
6. **页脚** 左＝项目名（读 `storyboard.json` 的 `slug`，白字粗体）/
   右＝系列徽章「项目日报 · 每天一个Github热门项目」（浅蓝常规体），**与画面徽章逐字一致**

## 三、垂直空间预算（最容易翻车的地方）

各段加起来必须 ≤100%，超了模型会自作主张砍掉某一段：

| 段 | 占比 |
|---|---|
| 顶部留白 | 18–25% |
| 标题 | ~10% |
| 黄标签 | ~9% |
| 呼吸空隙 | ~3% |
| 主视觉（话筒） | 30–40% |
| 主体底座（硬盘盒） | ~15% |
| 底部净空（页脚落这） | ≥10% |

⚠️ **实测教训**：把顶部留白从「五分之一」加码到「四分之一」后，模型**把整组主体一并下移**，
底部净空从 13.2% 掉到 5.8%。

**留白不是免费的** —— 加顶就必须减主体，否则一定从底部扣。
两端都要宽松，唯一解是缩主体（话筒降到约 1/4 画幅高、底座收窄），不是继续加留白。

### 三版实测留档

| | v1 | v2 | v3 |
|---|---|---|---|
| 顶部留白指令 | 五分之一 | 五分之一 | **四分之一** |
| 标题顶距 | 3.6%（**1:1 会被切**） | 12.6%（余 1px） | **20.5%（余 123px）** |
| 底部净空 | 7.6% | 13.2% | **5.8%** |
| 结论 | 不可用 | 1:1 余量太薄 | 当前采用 |

1:1 中心裁切线 = **12.5%**（小红书个人主页网格）。标题顶距低于它就会被切掉字头 ——
**这是最常见的翻车点**。

## 四、提示词要写死的五件事

0. **🚫 生图提示词里不得出现页脚 / 徽章 / 水印类文字**（2026-09-18 实测翻车）。
   页脚「左项目名 / 右系列徽章」**只由 `fix_cover.py` 补** —— 提示词里写了，
   生图模型画一份、脚本再补一份，成图上就是双份；水印同理，模型仿一个右下水标，
   去水印脚本还得额外擦。提示词末尾必须带否定句：
   「除标题和标签外画面无任何其他文字，无页脚，无徽章，无水印」。
   同时模型有把标题画两遍的倾向，要写明「标题只出现一次」。
1. **文字最小化**：全画面中文只留标题 + 数据标签，其余交给道具。
   中文越少，模型写错字概率越低。
2. **道具的形态、位置、遮挡关系**：无人像时层次感只能靠道具承担，要写明
   「谁从下往上遮住谁的下缘约多少」，否则整张会退化成一张纯字海报。
   （若标题已下移、与道具不再相邻，**就不要硬写遮挡** —— 那会把标题重新拽回顶部，
   层次感改由声波 / 光效穿过中间空隙来承担。）
3. **明确的边距约束**：「距左右两边至少保留约 12% 边距」—— 不写就没有安全区。
4. **底部留白单列一句**：「主体底边与画面底边之间保留约六分之一的完全空地面，
   不放任何元素」。页脚要写在这条带子里，不预留就会压主体。

## 五、出图后必查

`fix_cover.py` 会自动体检并打印（阈值已固化在脚本里）：

- 画幅是否 3:4（不是就自动中心裁到 3:4）
- **标题顶距 vs 1:1 裁切线（12.5%）** —— 顶距不够会切掉标题字头
- 黄标签的行段位置
- **主体是否侵入页脚带**（硬判据）/ 底部净空 ≥10%（美观提示）
- 产出 `crop-1to1-preview.png` 供肉眼复核

另外必须**逐字核对**画面文字（标题 + 星数），错字只能重跑生图。

⚠️ 四个必踩的坑见 `pitfalls.md` **P19（`raw.png` 命名）、P20（水印中值差分）、
P21（页脚贴底 + 体检顺序）、P26（提示词含页脚 → 双份页脚）**。

## 六、参数

```bash
"$PY" scripts/fix_cover.py                          # 全部走约定，通常不用带参
"$PY" scripts/fix_cover.py --slug=Foo --badge="..." # 覆盖项目名 / 徽章
"$PY" scripts/fix_cover.py --no-wm                  # 画面本来就干净时跳过
"$PY" scripts/fix_cover.py --wm-roi=0.78,0.90       # 水印位置与默认不同时
```

**输入固定读 `cover/raw.png`** —— 生图后第一件事就是改名，不要用 glob 排序去找（P19）。

产出：

```
cover/raw.png               生图原图（必须叫这个名字）
cover/cover.png             后期完成 1152×1536
cover/cover-1440x1920.png   与成片同规格
cover/crop-1to1-preview.png 1:1 中心裁切预览
```
